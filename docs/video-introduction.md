## 1080p 高清重录

此前文件虽为 1920×1080，但录制与多次剪辑经过 VP8、H.264 等多代有损压缩。旧模型 CSS 画布为 750×1200，随后合成为更大的角色区域；历史 DPR 未记录，不能将 CSS 尺寸当作当时实际渲染像素。

新录制显式使用 1500×2400 WebGL 画布、8192 最大贴图与抗锯齿，动作和物理按 60Hz 推进，逐帧输出 1920×1080、30fps 无损 RGB 素材。它是当前模型的离线脚本表演，不是对旧视频放大或插帧。口型使用原 WAV 的音频能量驱动；录制时不调用真实大模型或播放声音。

当前 UI 以最终内框 1504×846 原生捕获，菜单从官方 SVG 与代码绘制为 960×540 的明确示意；不放大原 58 像素悬浮球截图。中间合成保持 RGB/FFV1 无损，最终统一绘制字幕、转换 BT.709/yuv420p，并以 H.264 CRF15/slow 编码一次。最终原 AAC 音轨直接复制并校验哈希，37 条字幕与 7 个章节保持原时间线；总计 3636 帧、121.2 秒。

摸头段另行对齐“松手以后”的旁白：原音频提示约在素材 7.8267 秒，重录实际松手约 7.8333 秒，末段展示收手，保留两秒后的闭眼抚胸过程。

复建需要原 `video014` 素材工程、已有旁白/图文、用户版前端构建、本地模型、普通 Electron 环境、Node.js、Python/Pillow 和 ffmpeg。以下命令使用全新的默认 `output/video1080`；已交付成片存在时请另设输出目录并相应调整各入口路径：

```powershell

electron scripts/record-promo-hq.cjs --manifest=output/video1080/capture-jobs.json --out=output/video1080/capture --model="<模型目录>"
electron scripts/record-promo-hq.cjs --manifest=output/video1080/capture-jobs-pet-sync.json --out=output/video1080/capture-pet-sync --model="<模型目录>"
electron scripts/record-ui-promo-hq.cjs --static-root=output/build/user --out=output/video1080/ui
python scripts/rebuild-promo-hd.py --project "<原素材工程>/output/video014" --assemble
```

录制使用独立 profile 和随机回环服务，不访问用户真实聊天或账号。素材、成片、模型与配音权重留在忽略目录，不随源码推送。成片校验位于 `output/video1080/final/qa/validation.json`，包括分辨率、帧数、完整解码和原音轨一致性。

## 使用方法：适合置顶评论或单独教程

1. **打开与摆放。** 启动程序，点击悬浮球打开聊天。悬浮球可单独拖动；角色通过设置中的“移动 / 锁定桌宠”进入移动模式。在角色上滚轮缩放，支持 0.5～4 倍，可把部分身体放到屏幕外，摆成角落半身。右键悬浮球可隐藏／显示角色，或“退出大肥鱼”关闭整个程序。
2. **聊天与声音。** 首次为自动模式，DSH 聊天桥就绪后接入；MCP 表演状态和对话来源分开显示，只连 MCP 时还不能从聊天框发送。Codex 仅手动选择；旧保存来源需要时可切回自动。默认晓伊在线语音，也可选 Windows 系统语音或自定义 TTS API；设置修改后保存。Ctrl + Alt + Space 打开或收起聊天；Ctrl + Alt + Backspace 停止当前说话、生成和动作。
3. **检查表现。** “小表情”单独预览脸；“肢体”单独预览身体，并提供情境组合。它们是两条独立通道，不需要每次换脸都重新抬手。外部智能体先读取能力表，再按标签选择支持的表现。
4. **桌面互动。** 头部按住并移动可持续摸头，超过 2 秒进入闭眼脸红的双手抚胸。桌面任意位置持续按住左键会触发视线跟随，可在设置关闭。不要开启“完全鼠标穿透”后又期待点击角色有反应。
5. **道具与个性化。** 在肢体页打开戴盆，头部点击变为敲击；摘盆恢复摸头。可切换两种敲击音效。胸前轻点按完整一轮递进，播放中连点不排队；第三轮后摸头安抚，再轻点触发心动并重置。“调节”和单个表情微调即时保存。
6. **一起看。** 在 Chrome / Edge 安装扩展并配对，开启“一起看”后主动分享页面或选区。角色空闲且对话可用时，页面分享也可能触发自动短评并使用模型额度。普通 API 可分析内容；DSH 搜索还需配置可信只读工具。关闭一起看会清空页面上下文，重新开启后需要再次主动分享。

配对和 API 配置镜头只展示完成后的状态，不把配对码、Key 或私人聊天录入成片。

## 文案边界

- 用“按语境选择已有表现”，不写“无限自由生成动作”。当前手臂复用已有姿态和专用适配。
- 用“实际语音驱动开合”，不写“逐字精准口型”。当前是音频能量驱动，尚非完整音素口型。
- 用“支持 Chrome / Edge 主动分享页面”，不写“自动看见整个屏幕”。
- 用“可连接智能体和语音服务”，不写“整套 AI 无需网络或完全免费”。本地摸头和敲盆无需大模型请求，对话和语音取决于配置。
- 当前源码与两版 Releases 已公开；模型和素材仍遵循各自许可，应用源码公开不改变它们的授权范围。

## 已制作的增补段落

制作工程位于本机被忽略的 `output/video014/`；成片、模型、配音权重和私人环境数据不随源码推送。

- `final-v2`：在摸头之后加入轻点彩蛋，完整展示三轮反应、摸头安抚、心动及重置。`scripts/extend-promo-easter.py` 复用旧片段，按实际句组音频加入必要展示停顿。
- `final-v3`：在日常桌面操作之后加入悬浮球右键菜单：打开聊天、暂时隐藏／显示、退出大肥鱼，说明收起窗口与退出程序的区别。沿用诗歌剧配音，保留彩蛋章节。

菜单段使用真实悬浮球截图和明确标注的放大操作示意，未将其宣称为原生菜单实录。原生截图出现 DPI／窗口边界异常，因此没有采用。用 Electron 运行 `scripts/record-menu-promo.cjs --verify-only`，可在隔离 profile 验证真实菜单的隐藏、显示、退出回调；`scripts/video-menu-panels.py` 生成示意面板，`scripts/video-menu-graphics.py` 生成图文，`scripts/extend-promo-menu.py` 生成新时间线，最后用 Python 运行 `scripts/assemble-promo.py --assemble --tag final-v3 --reuse` 合成。脚本依赖本机已有制作工程和素材，不是干净克隆后的一键成片命令。

每次增补都保留旧成片，并重算 SRT 和章节偏移。新增解说由独立的 `narration-easter`／`narration-menu` 配音清单提供，不重新生成已经验收的旧旁白。
