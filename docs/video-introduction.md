## 使用方法：适合置顶评论或单独教程

1. **打开与摆放。** 启动程序，点击悬浮球打开聊天。悬浮球可单独拖动；角色通过设置中的“移动 / 锁定桌宠”进入移动模式。在角色上滚轮缩放，支持 0.5～4 倍，可把部分身体放到屏幕外，摆成角落半身。摆好后退出移动模式。
2. **聊天与声音。** 设置中选择已配置好的对话提供方。桌宠默认使用晓伊在线语音，也可切换 Windows 中文系统语音，或者独立配置兼容 TTS 服务。输入后发送，复杂问题可以再要求展开。Ctrl + Alt + Space 打开或收起聊天；Ctrl + Alt + Backspace 停止当前说话、生成和动作。
3. **检查表现。** “小表情”单独预览脸；“肢体”单独预览身体，并提供情境组合。它们是两条独立通道，不需要每次换脸都重新抬手。外部智能体先读取能力表，再按标签选择支持的表现。
4. **桌面互动。** 头部按住并移动可持续摸头，超过 2 秒进入闭眼脸红的双手抚胸。桌面任意位置持续按住左键会触发视线跟随，可在设置关闭。不要开启“完全鼠标穿透”后又期待点击角色有反应。
5. **道具与个性化。** 在肢体页打开戴盆，头部点击变为敲击；摘盆恢复摸头。可切换两种敲击音效。“调节”控制动作、物理反馈和互动强度，“小表情”里微调某一个表情，设置自动保存。
6. **一起看。** 在 Chrome / Edge 安装项目扩展并完成配对，打开聊天页的“一起看”，主动分享页面或选区。需要时在扩展开启标签页跟随；关闭一起看或停止分享即可结束。普通兼容 API 可以分析分享内容，进一步搜索需要提供方本身具有对应能力。

配对和 API 配置镜头只展示完成后的状态，不把配对码、Key 或私人聊天录入成片。

## 录制素材清单

- 1 段连续实录：思考状态 → 回复开场 → 讲述动作承接 → 停顿 → 收手。
- 1 段自主编排：同一会话里安慰、事情解决、恢复平静，记录真实选择。
- 1 段手动预览：表情与肢体分别展示；字幕标“手动预览”。
- 1 段持续摸头和松手，不剪掉两秒触发过程。
- 1 段敲盆与音效切换；保留原声，降低背景音乐。
- 1 段桌面摆放、滚轮缩放、悬浮球拖动和光标跟随。
- 1 段个性化调整前后对比，不改变录屏缩放来夸大差异。
- 1 段主动分享网页后的实际对话；如展示搜索，保留真实来源依据。
- 结尾放原模型作者署名和项目入口。画面由手动触发时不要标成“AI自主选择”。

## 文案边界

- 用“按语境选择已有表现”，不写“无限自由生成动作”。当前手臂复用已有姿态和专用适配。
- 用“实际语音驱动开合”，不写“逐字精准口型”。当前是音频能量驱动，尚非完整音素口型。
- 用“支持 Chrome / Edge 主动分享页面”，不写“自动看见整个屏幕”。
- 用“可连接智能体和语音服务”，不写“整套 AI 无需网络或完全免费”。本地摸头和敲盆无需大模型请求，对话和语音取决于配置。
- 当前代码仓库为私有，未改变可见性前不要写“已经开源、任何人可下载”。公开代码也不代表可以重新分发模型素材。

## 已制作的增补段落

制作工程位于本机被忽略的 `output/video014/`；成片、模型、配音权重和私人环境数据不随源码推送。

- `final-v2`：在摸头之后加入轻点彩蛋，完整展示三轮反应、摸头安抚、心动及重置。`scripts/extend-promo-easter.py` 复用旧片段，按实际句组音频加入必要展示停顿。
- `final-v3`：在日常桌面操作之后加入悬浮球右键菜单：打开聊天、暂时隐藏／显示、退出大肥鱼，说明收起窗口与退出程序的区别。沿用诗歌剧配音，保留彩蛋章节。

菜单段使用真实悬浮球截图和明确标注的放大操作示意，未将其宣称为原生菜单实录。原生菜单截图在录制环境出现 DPI／窗口边界异常，因此没有采用。`scripts/record-menu-promo.cjs --verify-only` 在隔离 profile 验证实际生产菜单的隐藏、显示、退出回调及窗口销毁；`scripts/video-menu-panels.py` 生成标有“菜单操作示意”的面板，`scripts/video-menu-graphics.py` 生成章节图文，`scripts/extend-promo-menu.py` 生成新时间线，再由 `scripts/assemble-promo.py --assemble --tag final-v3 --reuse` 合成。

每次增补都保留旧成片，并重算 SRT 和章节偏移。新增解说由独立的 `narration-easter`／`narration-menu` 配音清单提供，不重新生成已经验收的旧旁白。
