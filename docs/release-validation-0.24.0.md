# 0.24.0 两版验收记录

日期：2026-11-03。[文档导航](README.md)

本版在 0.23.1 稳定渲染和原生保护区优化之上整理发行边界，不新增模型动作或改变既有表情编排。

## 验证结果

- 无桌面 CI：380/380 通过；TypeScript 检查、两版 Vite 生产构建与受限构建通过。
- 安装器：隔离 PowerShell 测试 1/1 通过，覆盖同版本两版并存、重复安装、拒绝跨版根目录与元数据错配、旧用户包兼容及目录边界。使用隔离 LOCALAPPDATA、无快捷方式，不启动被安装程序。
- 两个真实发行包：分别加载包内 main/preload/React、真实 Live2D 模型与随机回环服务，2/2 通过。原生窗口保持隐藏、模拟可见性与鼠标观察器；没有调用外部大模型、TTS 或用户的 DSH。

## 用户版

旧配置中的省资源、GPU 缓存和兼容快照不会覆盖高清稳定策略。模型加载、真实摸头与隐藏后恢复通过；日常动作、表情、调节、道具和移动入口保留，MCP avatar_state 握手正常。

性能/实验设置、阶段彩蛋测试和 DSH 深层诊断从界面构建中裁掉；用户 JS 不包含 GPU 计时扩展或 render-sample 采样调用。运行期间接受的自动性能上报为 0；八项调试 IPC 均拒绝，已配对 GET /api/performance 返回 404，状态中的渲染诊断为 null，MCP 连接状态仍保留。实际尝试打开 DevTools 也被禁止。

用户包无前端开发源码、测试目录、构建脚本与源码映射；保留运行必需模块、使用指南、素材归属与依赖许可证。

## 开发版

旧画质与实验配置可用于对照；性能上报、性能 API、复制报告和 DevTools 通过实际验证。完整日常功能、摸头与隐藏恢复、MCP 握手正常。默认不抢占用户版全局快捷键。

源码、测试、构建配置、锁文件与维护指南位于 resources/app；开发依赖由 npm ci 安装。当前源码探针允许没有 Git 的开发 ZIP，保留源码 SHA 并记录 working-tree/no-git；历史基线仍需要 Git 仓库和对应提交。

两版配置、安装根目录、默认服务与专用 DSH 端口分开。新开发 profile 使用自己的空 DSH_HOME，不自动迁移用户账号或会话。浏览器扩展分别只请求 39181/39182 对应本机服务的权限。

## 边界

本次没有重新调用真实 DSH 模型，也没有重新评估远端电脑帧率；旧性能结论仍见 0.23.1 记录。双版测试使用实际模型与窗口实现，但不替代所有设备的物理鼠标与安装验收。模型、个人会话、凭据和测试产物均不进入发行包。
