# 发行版快速开始

适用版本：0.23.0；更新日期：2026-11-03。[返回文档导航](README.md)

## 准备

- Windows 10/11 x64，显卡支持 WebGL。
- 一份你有权使用的完整 Live2D 模型。当前手臂、表情与触摸交互针对 DeepSeek-chan 校准；换成其他模型不保证动作适配。
- 要用 DSH 聊天时，先安装 DeepSeek Harness，并在 DSH 中配置好模型，确认能够正常聊天。已有验证版本为 `0.2.1-rc.2`；其他版本需检查插件兼容性。

发行包包含桌面运行环境，普通用户不用安装 Node.js、npm 或开发工具。模型原件、DSH、模型账号和用户会话需要自行准备，不随程序分发。

## 安装与第一次打开

1. 将正式 ZIP **完整解压**到普通用户目录，在解压目录中运行随包的 `Install.ps1`。0.23.0 安装到 `%LOCALAPPDATA%\Programs\DeepSeekChan\app-0.23.0` 并创建快捷方式；以后每个版本有自己的 `app-<版本号>` 目录。不想安装快捷方式，也可以将完整解压目录作为便携版直接使用。不要在 ZIP 预览中运行，也不要只复制 exe。
2. 双击“大肥鱼”快捷方式或 `DeepSeek-chan.exe`，以当前 Windows 用户正常运行，不需要管理员权限或 `--no-sandbox` 参数。
3. 在首次向导中选择包含 `.model3.json` 的模型文件夹，保留原有贴图、动作和物理文件结构。
4. 等角色显示后，点击悬浮球打开聊天窗口。先在“小表情”和“肢体”中各预览一个动作，确认模型加载正常。

用户数据放在程序文件夹**旁边**的 `DeepSeek-chan-data`。推荐安装位置对应 `%LOCALAPPDATA%\Programs\DeepSeekChan\DeepSeek-chan-data`。这里保存偏好、配对信息和 DSH 会话引用；模型仍位于用户选择的原文件夹。

安装脚本可在 PowerShell 中运行：

```powershell
powershell -NoProfile -File .\Install.ps1
```

发布 ZIP 旁的 `.zip.sha256` 文件记录归档校验值；ZIP 内 `release-manifest.json` 记录逐文件校验值。也可以让脚本校验旁边的 ZIP 校验文件并从 ZIP 安装：

```powershell
powershell -NoProfile -File .\Install.ps1 -Archive .\DeepSeek-chan-0.23.0-win32-x64.zip
```

校验值不能代替确认下载来源。当前包未做代码签名。安装脚本只写当前用户目录，不更改安全标签或申请管理员权限。不同版本安装到各自目录，并把快捷方式指向新版本；同版本只有内容完全一致时才允许重复安装，不擅自覆盖异常文件。

## 首次接上 DSH

打开“设置 → 连接 DeepSeek Harness → 初次配置／升级接入”。确认使用自己的 DSH 安装与 home，然后明确选择一种会话模式：

| 模式 | 适合的情况 | 会话行为 |
|---|---|---|
| A · 接到已有会话 | 希望继承已有角色、人设和聊天上下文 | 选择具体会话；桌宠与该会话共享上下文 |
| B · 新建独立桌宠会话 | 希望桌宠有自己的聊天 | 首次创建后保存引用，以后重启继续使用 |

生成接入提示词并发给自己的 DSH 智能体，让它根据本机路径加载 MCP 和聊天桥。只需要在首次接入、桥插件升级或安装路径变化时做这一步。不要从别人截图中抄配对码、会话 ID 或电脑路径。

从旧版升级到 0.23.0 时，等当前 DSH 工作结束，再正常更新并重新加载桥插件一次。`/api/state` 的 `dsh.promptProtocol` 为 `2` 后，桌宠发到 DSH 的消息只包含本次正文，规约和网页引用由隐藏提示通道提供。仅重启大肥鱼不会替换 DSH 已加载的旧模块；无需删除原会话或 session 文件，旧历史也不会被自动清理。

默认对话来源是“自动 · 优先 DeepSeek Harness”。桥就绪后显示 DeepSeek Harness；没有聊天桥时显示未连接，不会偷偷改用 Codex。若你曾手动选择其他来源，自动连接会尊重原选择；要改回自动模式，请在设置中选择并保存。

接入后分别查看三项：

| 状态 | 说明 |
|---|---|
| 聊天桥就绪 | 桌宠能把消息送入已配对的 DSH 会话；模型凭据仍由 DSH 管理 |
| MCP 接口就绪 | 桌宠控制服务实际响应了工具发现 |
| DSH 工具就绪 | DSH 的真实工具目录已注册角色工具，包括 `avatar_reply` |

只有 MCP 接通不能代替聊天桥。正常表演使用 DSH 原生工具：智能体正常组织回复，通过 `avatar_reply` 安排表情、动作和语音。详细操作交给智能体阅读[DSH 操作指南](dsh-agent-guide.md)，动作选择可读[模型控制快速指南](model-control-quickstart.md)。

## 以后怎么打开

- **DSH 仍在运行：** 打开大肥鱼后等待自动恢复，必要时点“连接／重新连接”。无需重新发接入提示词，也不用重启 DSH。
- **已登记的 DSH 后端没有运行：** 点“启动已配置的 DSH”。这是一次明确的用户操作，后端首次启动需要自己的初始化时间。
- **DSH 显示正在使用，但未完成桥接：** 展开诊断，按当前实例加载配置；不要另开一套 home 或重复新建会话。
- **旧桥需要升级：** 在 DSH 工作结束后重载一次新版插件。只更新桌宠画面而未修改桥代码时，不必重载 DSH。

连接恢复不调用大模型。界面上的“已接入 · 空闲”表示暂时没有工具调用，不是断线。桌宠不会为了恢复连接结束现有 DSH 进程。

## 两分钟检查

1. 在大肥鱼中发一句：“这是功能测试，请用开心点头说一句我在这里。”确认文字、声音和角色动作出现；默认晓伊语音需要联网。
2. 点击停止，确认声音与本轮动作结束。摸头、预览小表情仍应工作。
3. 保持 DSH 运行，右键悬浮球选择“退出大肥鱼”，再打开大肥鱼。确认聊天与工具自动恢复，原会话继续存在。
4. 空闲一会再聊天，确认没有为了恢复工具状态创建新会话。

要检查更多表情、肢体和嘴型，可使用[模型控制测试集](model-control-evaluation.md)。不需要智能体真的执行办公或系统任务。

## 更新和迁移

更新前正常退出大肥鱼，并保留程序目录旁的 `DeepSeek-chan-data`。不要将个人数据、模型、配对码或 DSH 日志放进要发给别人的 ZIP。

运行新版本的安装脚本即可写入新的 `app-<版本号>` 目录，并更新“大肥鱼”快捷方式。旧版本目录保留，各版本共享同一个 `DeepSeek-chan-data`。不要同时运行两个版本。需要回退时，先退出当前版本，再打开旧版本目录中的 exe；旧版读取新版设置的兼容性仍应按该次版本说明检查。

看到“同版本目录内容不一致”时，保留现有程序与数据，按提示核对，不要删除整个 `DeepSeekChan` 文件夹。安装脚本不会代替你搬运另一处安装中的私人配置。

如果将程序从测试目录搬到新目录，旧 DSH 登记中的桥和 token 文件路径可能仍指向旧位置。保留原 A/B 选择、会话引用与配对文件，然后在新位置重新确认接入配置；由 DSH 在方便的时候加载新的桥路径。不要把旧路径登记直接当作新安装有效，也不要为了更新重新创建 B 会话。一般用户无需手动编辑这些文件。

智能体沙箱或受限测试目录可能带有低完整性安全标签。由其中的程序启动 DSH 时，即使普通双击也可能无法写入用户自己的 `.dsh` 配置，出现 `EPERM`。发布版应从正式 ZIP 重新解压到普通用户目录；不要通过改安全标签、关闭防护或管理员运行来掩盖这个问题。诊断仍报错时保留脱敏的错误摘要，交给维护者核对。

## 常用入口

点击悬浮球聊天，拖动悬浮球调整位置；右键可隐藏角色、重新显示或退出。仅收起聊天窗不会退出程序。“设置”页的对话来源、声音和回复节奏需点“保存设置”；“调节”与小表情微调即时保存。

浏览器一起看需单独安装随包扩展并主动分享网页；具体步骤见[README](../README.md#chrome--edge-一起看)。聊天文字与分享的页面会发送给所选对话服务，默认在线语音会发送待朗读文字；模型文件保留在本机。

## 给发行维护者的检查

1. 执行 `npm run package` 和 `npm run release`，保留 ZIP、旁边的 `.zip.sha256` 与 ZIP 内 `release-manifest.json`；不要把本机 `DeepSeek-chan-data`、模型或日志附在包里。
2. 从最终 ZIP 在普通用户目录安装，验收首次配置、真实 DSH 对话和表演，以及只重启桌宠后的恢复。模拟测试通过不能替代这一步。
3. 保留 Electron、Chromium、Live2D 与语音模块的随包许可证。模型由用户从授权来源自行准备，不随程序发包。
4. 当前经典钢管音效来源页未标注独立的再发行许可，详见[音效来源](audio-sources.md)。公开发包前应确认其再发行授权，或替换为可分发音效；目前的本地候选包不能据此宣称已获授权。
5. 当前程序未做代码签名，发布说明应如实标注，不宣称已签名或已经上架。
