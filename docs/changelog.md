# 版本变化

当前版本：**0.24.0**。整理日期：**2026-11-03**。[返回文档导航](README.md)

## 0.24.0：用户纯净版与智能体开发版

- 同一源码分别构建用户版与开发版，发行文件名和安装元数据明确区分。
- 用户版固定高清，移除画质对照、实验缓存／快照、性能采集、深层诊断与强制彩蛋阶段预览；正常表情／肢体预览、微调、真实互动和所有正式模型控制工具保留。
- 调试入口同时在界面、原生 IPC 与服务接口按版本限制；用户版不运行性能采样，开发版保留完整诊断。
- 开发版附应用源码、测试、构建配置和维护资料；默认使用独立数据目录、端口和 DSH 配置，便于交给用户自己的智能体修改。
- 两版各有简明根 README；旧版优化记录继续保留为开发资料。

## 0.23.1：回调节奏与原生窗口更新

- 原生保护区域使用有界稳定包络，减少角色微小摆动时重复 `setShape`；保留原有最小保护边距，精确交互继续跟随实时模型，悬浮球和聊天窗口实时排除。
- 几何变化不再反复抬升工具窗口或重新设置桌宠置顶；显示、隐藏、置顶变化等专用生命周期仍恢复必要层级。
- 本机相同八场景对照中，`setShape` 调用 446→51，采样阶段重复 `moveTop` 674→0，绘制维持约 60fps；调用次数下降不能换算为目标电脑帧率提升幅度。
- 性能报告增加原始 rAF 回调频率、应用主动跳帧数量与同一报告窗口内的 CPU 均值，区分生命周期均值和近期动作，避免把已回到 idle 的窗口归为“想到了”。
- 每回调只更新有界数组与计数；隐藏恢复清除近期基线，不增加逐帧 IPC、GL 查询或独立计时器。回调进入与时间戳的差不被描述为 DWM 等待时间。
- 目标电脑已确认 0.23.0 的 `promptProtocol:2` 与纯正文消息生效；本项不扩大为所有 DSH 功能实测。原始数据解释、生产修改与验收边界见[0.23.1 记录](release-validation-0.23.1.md)。

## 0.23.0：DSH 清爽对话与帧节奏诊断

- DSH 聊天只发送最新用户正文；不重复镜像 DSH 已有历史，不再为压缩回复额外创建一个 DSH 回合。Codex/API 保留原有上下文与改写路径。
- 桥的 `promptProtocol: 2` 将简短规约与本次网页引用放入匹配回合的隐藏系统 section，网页仍按不可信材料处理；原生 `avatar_reply` 与 MCP 表演路径保留。
- 已有 A 会话在排队期间不受桌宠提示词／工具守卫影响；取消排队请求只删除对应收件箱条目，不取消正在工作的其他回合。B 会话仍从原 session 文件复用。
- 修正限帧时钟在时间戳量化／舍入时误跳帧的问题，保持动作真实时间、高刷新率上限与隐藏恢复规则。
- 增加默认不采样的 15 秒 GPU 计时，异步读取查询结果；不支持、计时失效或观察开销过高时明确显示原因，不使用 `gl.finish()`。
- 完整启用纯正文需要正常更新并重载一次 DSH 桥；不清理既有聊天历史。验证范围与待验收项见[0.23.0 记录](release-validation-0.23.0.md)，不代表目标电脑已经稳定 60 帧。

## 0.22.3：独占画布的状态管理

- 默认直接初始化本应用独占 GL 画布的已知状态，省去 SDK 每帧外部状态快照查询；保留兼容快照开关、原绘制／蒙版算法和旧路径回退。
- 增加实际 SDK 保存／恢复调用次数及旁路计数，避免把蒙版网格次数误认为状态快照次数。
- 包含固定“想到了”与思考到语音交接的像素回归；GPU 数据复用仍为独立实验项，不擅自改变用户已有选择。
- 模型重载时清除旧性能样本，并用渲染代数拒绝迟到消息；诊断增加运行标识和渲染器实际档位，减少跨进程或重载窗口的误读。
- 具体现场结论、验证结果和目标机复测步骤见[状态回读优化](owned-gl-state.md)。

## 0.22.2：GPU 绘制路径对照

- 新增按网格、按渲染器独立复用的 GPU 缓冲，复用稳定的纹理坐标与索引，动态顶点继续校验更新；保持原有蒙版、着色器、图层顺序与镜像逻辑。
- “GPU 数据复用（实验）”默认关闭，可在性能设置中切换并恢复旧路径；不同机器的 CPU、显存与驱动收益存在差异。
- 诊断增加缓冲上传计数，并将绘制提交进一步拆成 SDK 状态保存、实际绘制和状态恢复，便于精确定位。
- 真实模型确定性画面对照未见像素变化；实际上传调用下降约69%，但尚未证明目标测试机的约41ms绘制等待已解决。详见[实测与限制](gpu-buffer-reuse.md)。

## 0.22.1：思考卡顿诊断

- 增加实际 WebGL 渲染设备、最近约两秒帧间隔／绘制耗时和超过 40ms 的长帧计数；用有界缓冲采样，隐藏期间不计为卡顿。
- 设置提供“复制性能诊断”；已配对智能体可读取 `/api/performance` 的近期记录，`/api/state.rendering` 返回摘要。
- 仅报告白名单性能字段，不读取聊天或密钥，不更改 GPU、Windows 安全或驱动设置。
- 新增真实原生透明窗口对照脚本。本机仍未复现用户录像中的思考跳帧，需要目标电脑诊断数据，不能仅凭离屏基准认定问题已解决。

## 0.22.0：交互与渲染性能

- 默认按物理内存选择均衡或高清，新增省资源选项；限制高刷新屏上的重复绘制，隐藏时暂停，显示后平稳恢复。
- 限制画布像素开销，在解码入口缩小贴图并及时释放临时资源；去掉不用的深度／模板缓冲，均衡档关闭多重采样。
- 合并拖动位移，对命中区域向外量化；相同原生窗口边界、鼠标穿透状态与置顶顺序不再重复设置。
- 保留头部、铁盆和身体交互，以及原有手臂层次、物理、DSH 原子工具和窗口透明度修复。
- 本机隔离实测均衡档稳态工作集从约 1077MiB 降到 751MiB；这不等于远端 16GB 电脑实测。完整口径见[性能记录](render-performance.md)。

## 0.21.1：发行包与首次使用

- 补充普通用户目录的 ZIP 安装流程、首次接入 DSH、三条连接状态及重启后的检查方法。
- 正常发行版使用 Electron 默认沙箱，不再要求快捷方式附带 `--no-sandbox`。
- 说明用户数据、模型和程序目录的边界；升级保留会话与配对文件，安装目录变化后重新确认桥路径。
- 用户级安装使用独立版本目录和共享数据目录，更新快捷方式时保留旧程序，可在正常退出后切回旧版本。
- 区分已有连接恢复与 DSH 后端冷启动，避免将测试目录的权限限制误报为模型登录失败。实际连接验收结果单独记录，不以本版本号代替实机验证。

## 0.21.0：一次配置与自动恢复

- 日常连接使用固定流程，首次配置／升级提示词与诊断单独展开；轮询保留未保存的 A/B 模式和会话草稿。
- 桥重连后立即认证并用真实 MCP 初始化／工具发现校验端点；单独检查 DSH 工具注册，不调用模型或表演工具刷状态。
- 保存接入身份、配置摘要与 A/B 选择；显式启动仅复用已登记实例，拒绝未知进程、占用端口、变更的配置和重复启动。
- 保留现有 DSH 原子工具、持久会话及 0.20.1 原生透明窗口修复。旧桥首次需重载一次，正常桌宠重启无需重启 DSH。

## 0.20.1：透明桌宠导致其他应用画面冻结

- 为 Windows 桌宠窗口设置原生 alpha 254/255，避免其整块工作区被 Chromium 当作不透明遮挡。
- 保留原有模型、输入保护、置顶偏好、DSH 原子工具和账户配置；不修改 DSH/Codex 的硬件加速或全局系统设置。
- 双进程对照测试确认：默认透明覆盖层令下层窗口 rAF 停止；原生透明属性恢复绘制，改变形状、置顶及隐藏再显示后仍有效。详见[诊断说明](windows-occlusion.md)。

## 0.20.0：用户级启动与 DSH 智能体接入

- 生成便携版和用户级桌面/开始菜单快捷方式，不要求管理员权限；双击即可启动，快捷方式带 `--no-sandbox`。
- 便携版数据固定放在 `release/DeepSeek-chan-data`，避开非 ASCII Roaming 路径下的进程锁问题，也不会被后续便携包替换。
- 首次启动向导：选择本地模型和对话来源，模型只需选一次。
- DSH 接入改为 A/B 两套可复制提示词：用户交给自己的 DSH 智能体完成 patch、MCP 和桥接，不再由桌宠自动启动或结束 DSH，也不显示倒计时/强杀流程。
- B 模式把新会话 ID 持久化到本地，重启复用；A 模式支持列出最近会话并选择。
- token 从本地文件读取，不再依赖 `L2D_BRIDGE_TOKEN` 环境变量。
- 旧长提示词 JSON 桥保留在高级兼容模式，作为回退和效果对照。

## 0.19.2：原生表演字段收紧

- `avatar_reply` 的 intent/emotion/gesture/bodyAnimation/combination/expressionCues 改为真实枚举，自造的 `hand_on_chest`、`wave` 等名称会被拒绝。
- 修正“害羞抚胸”：`gesture: chest` 不再落到只换脸的 `shy` 组合，而是自动使用作者预设 `reassure` 抚胸组合；后续 `bodyAnimation: talk` 接娓娓道来。
- 工具描述加入明确映射：抚胸 = combination `reassure` 或 gesture `chest`；娓娓道来 = bodyAnimation `talk`。新增回归测试。

## 0.19.1：独立置顶

- “置顶”从“一起看”中独立，聊天窗右上角图钉随时开启/关闭，不需要开启一起看。
- 置顶状态保存到桌面配置，重启保留；开启一起看不再自动改变置顶。
- 置顶时右键“暂时隐藏”仍保持隐藏，直到用户主动显示。

## 0.19：DSH 原生工具表演

- 新增 `avatar_reply`：一次提交最多 3 段完整表演计划，正常聊天文字和皮套表演分开，避免重复朗读。
- DSH 安装支持原生模式：智能体正常回复，需要表演时调用工具；不再每轮把长 JSON 规范注入用户消息。
- 安装时必须先问用户选 A“接到已有会话”还是 B“新建独立桌宠会话”，不设默认；A 还要选择具体会话。
- B 模式需要固定 `chatSessionId`，否则重启会新建会话、丢失上次上下文。
- 修复一起看开启置顶后，右键悬浮球“暂时隐藏”又被定时同步拉回来的问题。

## 0.18：DSH 优先与连接状态

- 将“对话来源”和“回复节奏”改为窗口内选项面板，支持滚动、键盘选择和自动上下展开。
- 分别显示 MCP 表演状态和对话来源。MCP 按最近活动判断，不能据此宣称聊天桥可用。
- 区分自动来源和手动选择。自动模式只优先 DSH；仅连 MCP 时禁用聊天并提示启用桥，DSH 断线／重启保持来源，Codex 仅手动选择。
- DSH 的凭据、取消、断线等错误独立处理。Codex 的权限／初始化失败提供安全诊断和退出码，不再一律归因登录。
- 升级保留旧版已保存来源；旧文件没有手选记录时，需要用户选择一次自动模式。

## 0.17：悬浮球快捷菜单

- 右键悬浮球可打开聊天、隐藏／显示桌宠、退出整个程序；左键聊天与拖动保持原行为。
- 首次启动取消默认 Codex，先显示待接入。0.18 在此基础上增加自动 DSH 解析。

## 0.16：DSH 作业与 CI 环境

- 桥工作目录跟随 `DSH_HOME`，保留 `chatCwd` 和 `dshHome` 覆盖，避免新 profile 写入常用 home。
- `npm test` 改为无桌面 CI；桌面与完整检查分别放到 `test:desktop`、`test:all`。
- 增加进程内 Rollup + TypeScript 构建及 JavaScript SDK 解压，保留普通构建路径。
- 记录用户在 DSH `0.2.1-rc.2` 干净 profile 完成的 MCP 十工具、状态桥、双向聊天和真实模型渲染验证。

## 0.15：默认晓伊声音

- 桌宠默认使用晓伊在线语音，语速 `+3%`、音调 `+8Hz`，无需额外 API Key 或 Python 环境。
- 设置中保留 Windows 系统语音和自定义语音 API；切换不清除已有语音配置。

## 0.14：能力标签与手臂校准

- 为 25 种表情、12 组肢体、12 个组合补充标签、适用／避免场景与推荐搭配。
- 修正镜像手臂的两侧肩袖归属，细化“娓娓道来”的手腕滞后与有界食指微弯。

## 0.13：组合开场与连续讲述

- 每轮可先播放一次合适的完整组合，语音继续时再由独立表情和肢体承接；短语音跳过完整组合。
- 移除“双手举指”和“两边说说”，保留双手抚胸及单手动作，形成当前 12 组独立肢体目录。
- 修正手臂层级与摸头后残影，并预热敲盆音效以减少首次播放延迟。

## 0.12：聊天窗位置与说话手势

- 聊天窗手动位置独立保存，摸头或失焦不再把已打开的窗口吸附到头部。
- 完善左右手动作和连续讲述，手势随实际语音推进、停顿及跨句衔接。

## 0.11：独立肢体预览

- 小表情预览与肢体动作分离；面部、身体和情境组合有各自控制入口。
- 调整眼神、头部、躯干与待机反应的配合。

## 0.10.1：隐藏后输入恢复

- 修复隐藏再显示后摸头、敲盆和胸前轻点失效，补充指针捕获取消与漏失松手恢复。

## 0.10：品牌、图标与安抚回路

- 界面名称统一为“大肥鱼”，使用 DeepSeek 标志与角色透明头像，兼容迁移旧品牌配置。
- 改进悬浮球拖动跟随。
- 第三轮胸前轻点后先摸头安抚，再轻点进入心动；结束后重置进度。
