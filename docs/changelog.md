# 版本变化

当前版本：**0.21.0**。整理日期：**2026-11-02**。[返回文档导航](README.md)

## 0.21.0：一次配置与自动恢复

- 日常连接使用固定流程，首次配置／升级提示词与诊断单独展开；轮询保留未保存的 A/B 模式和会话草稿。
- 桥重连后立即认证并用真实 MCP 初始化／工具发现校验端点；单独检查 DSH 工具注册，不调用模型或表演工具刷状态。
- 保存接入身份、配置摘要与 A/B 选择；显式启动仅复用已登记实例，拒绝未知进程、占用端口、变更的配置和重复启动。
- 保留现有 DSH 原子工具、持久会话及 0.20.1 原生透明窗口修复。旧桥首次需重载一次，正常桌宠重启无需重启 DSH。

## 0.20.1：透明桌宠导致其他应用画面冻结

- 为 Windows 桌宠窗口设置原生 alpha 254/255，避免其整块工作区被 Chromium 当作不透明遮挡。
- 保留原有模型、输入保护、置顶偏好、DSH 原子工具和账户配置；不修改 DSH/Codex 的硬件加速或全局系统设置。
- 双进程对照测试确认：默认透明覆盖层令下层窗口 rAF 停止；原生透明属性恢复绘制，改变形状、置顶及隐藏再显示后仍有效。详见[诊断说明](windows-occlusion.md)。

本页记录项目的功能演进；版本号不代表已创建同名 GitHub Release 或提供安装器。当前使用方法见[项目 README](../README.md)，实现细节见[维护指南](maintenance-guide.md)。

## 0.20.0：用户级启动与 DSH 智能体接入

- 生成便携版和用户级桌面/开始菜单快捷方式，不要求管理员权限；双击即可启动，快捷方式带 `--no-sandbox`。
- 便携版数据固定放在 `release/DeepSeek-chan-data`，避开非 ASCII Roaming 路径下的进程锁问题，也不会被后续便携包替换。
- 首次启动向导：选择本地模型和对话来源，模型只需选一次。
- DSH 接入改为 A/B 两套可复制提示词：用户交给自己的 DSH 智能体完成 patch、MCP 和桥接，不再由桌宠自动启动或结束 DSH，也不显示倒计时/强杀流程。
- B 模式把新会话 ID 持久化到本地，重启复用；A 模式支持列出最近会话并选择。
- token 从本地文件读取，不再依赖 `L2D_BRIDGE_TOKEN` 环境变量。
- 旧长提示词 JSON 桥保留在高级兼容模式，作为回退和效果对照。

## 0.19.2：原生表演字段收紧

- `avatar_reply` 的 intent/emotion/gesture/bodyAnimation/combination/expressionCues 改为真实枚举，自造的 `hand_on_chest`、`wave` 等名称会被拒绝。
- 修正“害羞抚胸”：`gesture: chest` 不再落到只换脸的 `shy` 组合，而是自动使用作者预设 `reassure` 抚胸组合；后续 `bodyAnimation: talk` 接娓娓道来。
- 工具描述加入明确映射：抚胸 = combination `reassure` 或 gesture `chest`；娓娓道来 = bodyAnimation `talk`。新增回归测试。

## 0.19.1：独立置顶

- “置顶”从“一起看”中独立，聊天窗右上角图钉随时开启/关闭，不需要开启一起看。
- 置顶状态保存到桌面配置，重启保留；开启一起看不再自动改变置顶。
- 置顶时右键“暂时隐藏”仍保持隐藏，直到用户主动显示。

## 0.19：DSH 原生工具表演

- 新增 `avatar_reply`：一次提交最多 3 段完整表演计划，正常聊天文字和皮套表演分开，避免重复朗读。
- DSH 安装支持原生模式：智能体正常回复，需要表演时调用工具；不再每轮把长 JSON 规范注入用户消息。
- 安装时必须先问用户选 A“接到已有会话”还是 B“新建独立桌宠会话”，不设默认；A 还要选择具体会话。
- B 模式需要固定 `chatSessionId`，否则重启会新建会话、丢失上次上下文。
- 修复一起看开启置顶后，右键悬浮球“暂时隐藏”又被定时同步拉回来的问题。

## 0.18：DSH 优先与连接状态

- 将“对话来源”和“回复节奏”改为窗口内选项面板，支持滚动、键盘选择和自动上下展开。
- 分别显示 MCP 表演状态和对话来源。MCP 按最近活动判断，不能据此宣称聊天桥可用。
- 区分自动来源和手动选择。自动模式只优先 DSH；仅连 MCP 时禁用聊天并提示启用桥，DSH 断线／重启保持来源，Codex 仅手动选择。
- DSH 的凭据、取消、断线等错误独立处理。Codex 的权限／初始化失败提供安全诊断和退出码，不再一律归因登录。
- 升级保留旧版已保存来源；旧文件没有手选记录时，需要用户选择一次自动模式。

## 0.17：悬浮球快捷菜单

- 右键悬浮球可打开聊天、隐藏／显示桌宠、退出整个程序；左键聊天与拖动保持原行为。
- 首次启动取消默认 Codex，先显示待接入。0.18 在此基础上增加自动 DSH 解析。

## 0.16：DSH 作业与 CI 环境

- 桥工作目录跟随 `DSH_HOME`，保留 `chatCwd` 和 `dshHome` 覆盖，避免新 profile 写入常用 home。
- `npm test` 改为无桌面 CI；桌面与完整检查分别放到 `test:desktop`、`test:all`。
- 增加进程内 Rollup + TypeScript 构建及 JavaScript SDK 解压，保留普通构建路径。
- 记录用户在 DSH `0.2.1-rc.2` 干净 profile 完成的 MCP 十工具、状态桥、双向聊天和真实模型渲染验证。

## 0.15：默认晓伊声音

- 桌宠默认使用晓伊在线语音，语速 `+3%`、音调 `+8Hz`，无需额外 API Key 或 Python 环境。
- 设置中保留 Windows 系统语音和自定义语音 API；切换不清除已有语音配置。

## 0.14：能力标签与手臂校准

- 为 25 种表情、12 组肢体、12 个组合补充标签、适用／避免场景与推荐搭配。
- 修正镜像手臂的两侧肩袖归属，细化“娓娓道来”的手腕滞后与有界食指微弯。

## 0.13：组合开场与连续讲述

- 每轮可先播放一次合适的完整组合，语音继续时再由独立表情和肢体承接；短语音跳过完整组合。
- 移除“双手举指”和“两边说说”，保留双手抚胸及单手动作，形成当前 12 组独立肢体目录。
- 修正手臂层级与摸头后残影，并预热敲盆音效以减少首次播放延迟。

## 0.12：聊天窗位置与说话手势

- 聊天窗手动位置独立保存，摸头或失焦不再把已打开的窗口吸附到头部。
- 完善左右手动作和连续讲述，手势随实际语音推进、停顿及跨句衔接。

## 0.11：独立肢体预览

- 小表情预览与肢体动作分离；面部、身体和情境组合有各自控制入口。
- 调整眼神、头部、躯干与待机反应的配合。

## 0.10.1：隐藏后输入恢复

- 修复隐藏再显示后摸头、敲盆和胸前轻点失效，补充指针捕获取消与漏失松手恢复。

## 0.10：品牌、图标与安抚回路

- 界面名称统一为“大肥鱼”，使用 DeepSeek 标志与角色透明头像，兼容迁移旧品牌配置。
- 改进悬浮球拖动跟随。
- 第三轮胸前轻点后先摸头安抚，再轻点进入心动；结束后重置进度。
