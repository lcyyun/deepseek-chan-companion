# 大肥鱼 · 用户版

版本 0.24.0。大肥鱼是在 Windows 桌面陪你聊天、做小动作和一起看网页的 Live2D 伙伴。用户版统一使用高清画质，保留日常互动与个性化调节，不提供测试开关。

## 安装与第一次见面

1. 完整解压名称包含 `user` 的 ZIP，在普通用户目录运行 `Install.ps1` 创建快捷方式；也可以直接打开 `DeepSeek-chan.exe`。不要只复制 exe。
2. 首次启动选择包含 `.model3.json` 的完整模型文件夹。模型需要自行准备，不包含在发行包里。
3. 打开悬浮球中的聊天窗口，在设置中连接自己的智能体。未连接也可以摸头、播放动作和使用本地互动。

普通运行不需要 Node.js，也不需要管理员权限。安装后可从桌面“大肥鱼”快捷方式启动。更新前正常退出大肥鱼，保留个人数据目录，再安装新版；旧版本目录保留。

## 连接自己的智能体

默认等待 DeepSeek Harness 的聊天桥，不会自动改用 Codex。设置页保留当前连接状态、连接按钮和首次配置入口。

使用 DSH 时，在首次配置中明确选择：接到已有会话，继承其人格和上下文；或者建立独立桌宠会话，之后继续复用。生成接入提示词，交给自己的 DSH 智能体完成连接。通常只需配置一次；日常直接连接，或在已登记的后端未运行时点击“启动已配置的 DSH”。

标题栏分别显示表演与对话状态：MCP 已接入表示智能体可以操控角色，聊天桥就绪才表示便携聊天窗口可以发送消息。DSH 断线后会保持原来源等待重连。也可以在设置里手动选择兼容 API 或 Codex；这些来源的账户、模型和网络服务由使用者自行配置。

## 悬浮球与摆放

点击悬浮球打开或收起聊天，拖动它调整位置；右键可暂时隐藏、重新显示角色，或退出整个程序。收起聊天窗口不会退出桌宠。

在设置或调节页进入“移动 / 锁定桌宠”，拖动角色摆放，在桌宠上滚动鼠标滚轮缩放。允许把部分身体移出屏幕，适合半身放在屏幕角落；找不到角色时使用“恢复位置”。位置与大小自动保存，聊天窗口和悬浮球也可独立摆放。右上角图钉控制角色置顶。

## 日常互动

- 点击头部可以摸头，按住并来回移动可以持续摸头；超过两秒进入闭眼、脸红的双手抚胸撒娇，松手后平滑恢复。
- 桌面任意位置持续按住左键，会触发视线与头部跟随；可在设置中关闭。开启完全鼠标穿透后，本地点击互动不可用。
- 戴上铁盆后，点击头部改为敲盆，伴随声音、惊吓和耳朵弹动；连击可反复触发。调节页可更换敲击音效和音量。
- 轻点胸前有三轮递进反应；每轮播放中重复点击无效。第三轮后先摸头安抚，再轻点会触发短暂心动，结束后重置。长按和拖动不算轻点。
- “肢体”页可播放动作和情境组合；“小表情”只预览表情，方便选择与微调。停止按钮可打断当前声音和动作。

## 调成自己喜欢的样子

“调节”页保留身体运动幅度、物理柔软度、视线跟随、脸红、盆下阴影及音量等选项。“小表情”可单独调整嘴角、眼睛、眉毛、张嘴与脸红，并保存为自己的偏好。预览是日常调节的一部分，用户版仍可使用。

用户版固定高清，以 60 帧为绘制上限，隐藏角色时暂停渲染。没有均衡、省资源、兼容快照或实验缓存开关；旧版保存的低画质与实验参数不会改变本版的高清策略。

## 聊天、声音与一起看

回复默认简短，想深入时再展开。设置页可选择朗读开关、回复节奏和声音；这些设置修改后点击保存。默认晓伊为在线语音，也可选 Windows 本地嗓音或自己的语音 API。口型跟随实际播放的声音，打断时停止后续播放。

Chrome 与 Edge 都可使用一起看：在设置中打开扩展目录，在浏览器扩展页加载已解压的扩展，填入桌宠设置中的配对码。打开“一起看”后主动分享当前网页或选中文字；停止分享或关闭一起看会清除共享页面。每次重新开启需再次授权跟随，不会默默读取其他页面。

配对码只用于本机连接，不要公开。模型文件留在本机；聊天文字、主动分享的页面和待朗读文本会根据所选服务发送到对应提供方。

## 遇到问题

| 现象 | 处理 |
|---|---|
| 模型不显示 | 重新选择完整模型目录，查看界面错误提示；设备需支持 WebGL |
| 表演已连接但不能聊天 | 按设置中的连接说明启用 DSH 聊天桥，不能只连接 MCP |
| 没有声音 | 检查朗读开关、音量和所选声音服务；默认在线语音需要网络 |
| 桌宠不响应点击 | 检查是否开启鼠标穿透，或仍处于移动模式；也可隐藏后重新显示 |
| 快捷键被占用 | 继续使用界面动作按钮，按提示检查其他软件快捷键 |
| 需要排查帧率或修改代码 | 使用单独的开发版，把源码和问题交给自己的智能体 |
