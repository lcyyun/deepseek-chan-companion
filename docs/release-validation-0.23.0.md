# 0.23.0 验证记录

状态：本次代码回归、本机 GPU 与生产桌面诊断入口验证通过；真实 DSH 新协议与目标电脑复验待部署后记录。日期：2026-11-03。[文档导航](README.md)

本文记录本次变更的验收口径；没有填写结果的检查不视为已通过，也不沿用旧版本的实机结果。

## 变更范围

- DSH 每轮只提交最新用户正文，不镜像旧回复，不额外发改写回合；短规则与当前网页资料进入匹配回合的隐藏系统 section。
- 保持原生 `avatar_reply`、MCP 表演、A/B 会话复用和 Codex/API 通路；排队取消不误取消 A 会话的原工作。
- 修正帧时钟对量化时间戳的误跳帧，保持固定频率上限、动作真实时间与隐藏恢复。
- 增加手动 15 秒 GPU 用时采集；默认关闭，不支持时说明原因，不强制同步 GPU。

## 本机生产 GPU 计时模块验证

隔离的可见原生透明窗口加载真实模型与工作区生产计时模块，未连接用户 DSH 或在线 TTS。CSS 画布 1708 × 912、DPR 1.5，实际画布 2562 × 1368；最大贴图 3072、无多重采样、GPU 数据复用关闭、独占状态路径启用。`idea` 为取得稳定采样窗口延长展示至 6 秒，不是线上语音回合复现。

15 秒取得 30 个有效样本，结束为 `completed`、`pending:0`，`disjointCount:0`、`timeoutCount:0`，轮询 CPU 最大约 0.10ms。各动作结果如下：

| 阶段 | 有效 GPU 样本 | GPU 均值 | 模型绘制速率 |
|---|---:|---:|---:|
| 待机 | 10 | 1.93ms | 约 60fps |
| 固定思考 | 10 | 2.30ms | 约 60fps |
| 想到了 | 10 | 1.94ms | 约 60fps |

思考帧间隔 P95 为 16.9ms。同一冻结姿态下关闭／开启 timer 的截图位图逐字节一致；隐藏后 `stopped` 且 pending 为 0，销毁后 `disposed` 且 pending 为 0。原始本机产物保存在忽略目录 `output/gpu-time-probe/production-timer-production-after-1708x912-dpr1.5-scale4-cy1.4/`，不随模型资产分发。

这些结果验证了本机模块的采样与清理行为，不能替代真实 DSH 回合或远端测试电脑验收。查询范围包含帧绘制状态设置、清屏和 SDK 绘制，不包含 DWM 最终呈现。

## 生产桌面入口验证

另一次约 41.3 秒的隔离检查加载真实 main、preload、React 与 Live2D，验证固定 15 秒请求、调用者身份、渲染代数、ACK 字段净化、5 秒超时、隐藏状态拒绝启动及模型重载清理 pending。实际按钮触发后得到 15 个 thinking 有效样本，最终为 `completed`；结果能通过现有 API 与复制报告读到，私密字段不泄露。诊断字段净化另有 4 项测试通过。

该轮自动化使用隐藏窗口，只验证控制与数据路径，其 FPS 不能作为可见桌面流畅度依据；上节的可见原生窗口计时是独立验证。没有借此宣称真实 DSH 模型回合或目标 16GB 电脑已验收。

## 部署后的验收

1. 正常更新完整集成目录，在当前 DSH 工作结束后重载对应桥一次。检查 `dsh.promptProtocol:2`，保留原 A/B 会话 ID、配对和 session 文件。
2. 从桌宠连续发送两轮短消息：DSH 只显示各自本次正文，没有旧回复和长规则；表演、语音仍正常，无第二条改写请求。旧聊天历史保留，不自动清理。
3. 在独立测试会话验证排队取消不会停止原工作；不要用用户尚未完成的重要任务试取消。
4. 目标测试机保留当前更顺的档位和模型大小，复现思考与“想到了”。先观察常态，再手动采集 15 秒 GPU 用时，约 20 秒后复制诊断。
5. 检查有效 GPU 样本、分阶段用时、帧间隔和实际画面。`unsupported` 或 `observer-overhead` 属于诊断边界，不代表零耗时。

本机结果不代表 RTX 4060／16GB 目标电脑已经稳定 60 帧。GPU 查询覆盖模型绘制，不包含 DWM 最终呈现；实际账号端到端与目标电脑流畅度需分别记录。
